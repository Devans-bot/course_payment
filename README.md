# 21-Day Health Action Journey

A Next.js landing page built with custom Vanilla CSS and the Poppins font family.

## Features
- **8 Dedicated Sections**: Hero, The Gap, The Journey, What We'll Work On, What's Included, FAQ Accordion, Enroll Card (₹5,100), and Closing CTA.
- **Modern White, Blue & Green Aesthetic**.
- **Hardware-Accelerated Scroll Animations** (Slide up, Pop, Staggered entrance).
- **Responsive & Lightweight**.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5189](http://localhost:5189) with your browser to see the result.
